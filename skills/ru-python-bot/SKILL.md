# Боты и приложения на Python

Прочитать соответствующий модуль references/core/software.md от корня системы, текущие материалы проекта и ограничения пользователя. Использовать только доступные инструменты и профильные навыки.

## Процедура

Прочитать проект, инструкции, зависимости, текущий запуск и логи. Найти конкретную причину сбоя до правки. Не обновлять весь стек ради локальной ошибки.
Отделить обработчики, бизнес-логику, хранение и внешние API. Секреты брать из настроек, не включать в репозиторий и вывод. Обработку событий делать устойчивой к повторам.
Для записи на услуги обеспечить уникальность слота и атомарное подтверждение. Для генерации медиа хранить состояние задачи и возвращать реальный результат, а не вечный статус.
Обработать таймауты, ограниченные повторы, ошибку провайдера и отмену. Не блокировать обработчик долгим вычислением. Не обещать доставку сообщения без ответа сервиса.
Проверить изменённый сценарий и связанные ошибки подходящими тестами. После деплоя проверить процесс и главный путь в разрешённой среде; недоступный VPS не считать проверенным.

## Результат и проверка

Выдать порученный результат и подтверждённые проверки. Обозначить нерешённые дефекты и недоступные проверки. При существенном исправлении сохранить правило в пределах проекта. Происхождение методик — [NOTICE.md](../../NOTICE.md).
