# Маркетинговые идеи для РФ

Российская адаптация `marketing-ideas` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../../references/ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Продукт, регион, задача роста, бюджет, команда, история попыток и ограничения.

## Порядок работы

1. Найти узкое место: о нас не знают, не понимают, не верят, не покупают или не возвращаются.
2. Просмотреть подходящие категории оригинального банка идей; выбрать только механики, применимые к бизнесу. Не считать перечень тактик обязательным планом.
3. Адаптировать канал и механику: локальные карты и партнёры, материалы под поисковый спрос, сообщества, объявления, демонстрации, повторный заказ, полезный инструмент.
4. Для каждой идеи описать аудиторию, действие, причину ожидаемого эффекта, ресурсы и измерение. Если нет денег — показать трудозатраты и ручной способ.
5. Оценить влияние, уверенность и усилия по объяснённой шкале; неподтверждённые оценки обозначить экспертными гипотезами.
6. Выбрать первые 3 идеи и небольшой проверочный запуск с критерием продолжения. Не возвращать ранее провалившуюся тактику без изменения причины провала.

## Результат

Ранжированный список идей и три пошаговых мини-плана с метрикой, затратами и сроком проверки.

## Проверка качества

У каждой идеи есть механизм результата и доступный способ исполнения; отсутствует обещание «бесплатных клиентов без усилий».
