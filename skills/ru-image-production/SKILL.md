# Создание и точные правки изображений

Прочитать соответствующий модуль references/core/media.md от корня системы, текущие материалы проекта и ограничения пользователя. Использовать только доступные инструменты и профильные навыки.

## Процедура

Определить создание или правку. Осмотреть исходники, назначить роль каждого: эталон личности/товара, объект правки или стиль. Не использовать стилевой пример как источник нового лица.
Записать неизменяемые детали и допустимые изменения. Для человека сохранять нужные лицо, позу, возраст, одежду и анатомию; для товара — форму и маркировку. Выбрать кадр и разрешение по результату.
Применить ImageGen. Для прозрачного фона указать реальную прозрачность. У каждой вариации сохранять общие ограничения; менять одну важную задачу.
Осмотреть изображение по фактическому результату: руки, края, отражения, текст, геометрия, количество объектов, соответствие эталону. При отклонении выполнять конкретную правку.
Не выдавать сгенерированный результат за документальную фотографию события или доказательство услуги. При нерешённом дефекте назвать его, не обещать точность по статусу генерации.

## Результат и проверка

Выдать порученный результат и подтверждённые проверки. Обозначить нерешённые дефекты и недоступные проверки. При существенном исправлении сохранить правило в пределах проекта. Происхождение методик — [NOTICE.md](../../NOTICE.md).
