# Каталоги, карты и профили компании

Российская адаптация `directory-submissions` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../../references/ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Тип бизнеса, география, реальные адреса, контакты, услуги, сайт, материалы и права управления профилями.

## Порядок работы

1. Сначала найти существующие карточки и дубли. Выбрать площадки по спросу: Яндекс Бизнес/Карты, 2ГИС, отраслевые каталоги; международные — при зарубежной аудитории.
2. Проверить, подходит ли формат компании правилам площадки. Не создавать фиктивную точку для онлайн-бизнеса и не обещать размещение без модерации.
3. Собрать единый набор названия, адреса, телефона, часов работы, услуг, цен и фото; адаптировать описание без набивки ключей.
4. Подготовить карточки и маршрут подтверждения владения. Фактическое размещение/изменение выполнять только в рамках поручения и доступов.
5. Запрашивать честные отзывы о реальном опыте без фильтра «только довольные». На критику отвечать по сути; не покупать рейтинг.
6. Отслеживать обращения, построения маршрута, переходы и продажи; каталоги не оценивать только по количеству ссылок.

## Результат

Приоритетный список площадок, комплект полей, найденные дубли, статус размещения и план измерения.

## Проверка качества

Карта подходит реальной модели бизнеса; нет гарантий рейтинга, поддельных отзывов и ложных адресов.
