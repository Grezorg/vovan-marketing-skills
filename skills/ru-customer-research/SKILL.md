# Исследование российских покупателей

Российская адаптация `customer-research` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../../references/ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Ниша, регион, сегмент, доступные отзывы/переписки/интервью и исследовательский вопрос.

## Порядок работы

1. Выбрать режим: анализ предоставленных материалов, открытые источники или план интервью. Реальные интервью проводить только при наличии участников и разрешённого канала.
2. Для локального бизнеса искать отзывы в Яндекс Картах и 2ГИС; для товаров — в карточках Ozon/Wildberries; для профессиональных ниш — тематические сообщества и отраслевые площадки. Проверять соответствие источника сегменту.
3. Для каждого наблюдения сохранять ссылку, дату, контекст покупки и тип автора. Убирать дубли, рекламные публикации и очевидно нерелевантные истории; не объявлять отзывы подлинными без проверки.
4. Кодировать триггер, прошлое решение, боль, критерии выбора, возражение, результат и фразу клиента. Частоту считать только внутри собранной выборки.
5. Для интервью спрашивать о последней реальной покупке, действиях и компромиссах; не подсказывать желательный ответ и не подменять спрос обещанием купить.
6. Собрать JTBD и 2–4 различающихся сценария покупки. Отдельно отметить недопредставленные группы и вопросы, которые нельзя решить по публичным отзывам.

## Результат

Таблица наблюдений с источниками; карта задач и возражений; словарь клиента; выводы для оффера и текста; план проверки пробелов.

## Проверка качества

Синтетические персоны обозначены как гипотезы. Цитаты дословны и кратки. Нет личных телефонов и имён из частных переписок в публичном отчёте.
