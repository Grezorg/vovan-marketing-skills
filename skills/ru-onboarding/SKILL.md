# Первая польза после регистрации

Российская адаптация `onboarding` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../../references/ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Ценность продукта, роли пользователей, событие активации, текущий путь и ограничения интеграций.

## Порядок работы

1. Определить наблюдаемую первую пользу, связанную с будущим удержанием; регистрация сама по себе не доказывает активацию.
2. Выделить короткий путь по роли: показать пример → выполнить действие → увидеть результат. Не навязывать полный обзор функций.
3. Дать полезные пустые состояния, демонстрационные данные с явной маркировкой и необязательный чек-лист. Пользователь должен иметь возможность пропустить обучение.
4. Проверить доступность внешних сервисов, оплаты и уведомлений для выбранного региона. Не требовать недоступную интеграцию ради прохождения обучения.
5. Сделать сообщения по событию затруднения: не завершил настройку, не получил результат, не нашёл следующий шаг; выбрать разрешённый канал и прекратить цепочку после успеха.
6. Измерять время до пользы, долю активации и удержание когорт. Сравнивать пользователей с одинаковым источником и задачей.

## Результат

Путь первой пользы, экраны/подсказки, события, условия напоминаний и план проверки активации.

## Проверка качества

Инструкция помогает выполнить реальную задачу; демонстрационные цифры не выдаются за результаты клиента.

## Углубление и продолжение

Для подробных методов, шаблонов и частных случаев открыть [оригинал onboarding](../../upstream/marketingskills/skills/onboarding/SKILL.md) и только нужные связанные материалы. Не выдавать прочтение заголовка за изучение всех references. Российский контекст определяет выбор каналов, примеров, оплаты и проверку местных требований. Не заменять исходные методы механической подстановкой названий сервисов.

Продолжение по необходимости: [signup](../ru-signup/SKILL.md), [emails](../ru-emails/SKILL.md), [analytics](../ru-analytics/SKILL.md), [churn-prevention](../ru-churn-prevention/SKILL.md).
