# Сообщество вокруг пользы

Российская адаптация `community-marketing` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../../references/ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Кому служит сообщество, общая задача, площадка, текущие участники, модераторы и бизнес-цель.

## Порядок работы

1. Сформулировать причину возвращаться, независимую от рекламы продукта: помощь коллег, совместная практика, локальная информация или обмен опытом.
2. Выбрать площадку по привычкам участников, поиску, уведомлениям и возможностям модерации; не переносить Discord/Slack по умолчанию.
3. Создать понятный вход: кому подходит, правила, первое полезное действие и знакомство без обязательного раскрытия лишних данных.
4. Планировать повторяемые форматы: разбор, вопрос недели, встреча, подборка, помощь участнику. Частоту соотнести с силами команды.
5. Разделить критику продукта, спор и нарушение правил. Не удалять содержательный негатив автоматически и не имитировать активность фальшивыми участниками.
6. Измерять долю активных/возвращающихся участников, время ответа, взаимопомощь и связанные с сообществом бизнес-действия; учитывать расходы модерации.

## Результат

Концепция, правила, сценарий входа, календарь полезных форматов и показатели здоровья сообщества.

## Проверка качества

Сообщество имеет собственную ценность; публикации, приглашения и сообщения не выполняются без нужного поручения.
