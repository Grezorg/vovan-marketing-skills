# Пример 1. Подтверждённые дефекты страницы

Исходник: [before.html](before.html). Это намеренно упрощённый учебный пример; наблюдения по коду не выданы за реальную аналитику бизнеса.

| Наблюдение | Почему мешает | Исправление в landing.html |
|---|---|---|
| Фиксированная ширина body 1100px, нет viewport | На узком экране содержимое не адаптируется | Гибкая ширина, viewport, мобильная сетка |
| Кнопка «Оставить заявку» ведёт на # | Не переводит к заполняемой форме | Ссылка #request на существующую секцию |
| Телефон без label, name и проверки | Непонятный ввод и отсутствие пригодной структуры формы | Подпись, тип tel, name, required и проверка формата |
| Кнопка показывает alert без обработчика доставки | Сообщение «Отправлено» не доказывает отправку | Явная демонстрационная проверка, без заявления о доставке |

Текущая улучшенная страница — [landing.html](landing.html). Браузерные проверки записаны в [checks.json](checks.json). При переносе в реальный проект необходимо подключить получателя и отдельно проверить получение заявки. Успех учебной формы не является доставкой.
