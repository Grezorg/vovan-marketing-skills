# Три примера законченных материалов

Все исходные данные вымышлены. Это воспроизводимые учебные материалы, не отзывы и не клиентские кейсы.

| Пример | Вход | Результат | Как проверить |
|---|---|---|---|
| Аудит | [Исходная страница](before.html) | [Замечания и исправления](audit.md) | Сопоставить каждое наблюдение с кодом |
| Лендинг | [Краткие условия](brief.json) | [Адаптивная HTML-страница](landing.html) | Открыть скачанный файл, проверить кнопку, пустую и корректную форму |
| Контент | Проблема из аудита | [Пост, сценарий, обложка и описание](content.md) | Центральный тезис совпадает с поведением исходной кнопки |

Файл HTML открывается локально в браузере. На GitHub отображается исходный код; скачайте файл через Raw/Download, если хотите посмотреть страницу. [Браузерные результаты](checks.json) отделены от проверки живой доставки: внешняя отправка отсутствует специально и явно обозначена в интерфейсе.

Начните собственную задачу: «Используй аналогичный процесс для моей услуги: …». Учебные цены, отзывы и факты не переносить в настоящие проекты.
