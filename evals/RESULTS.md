# Результаты Vovan OS 4.3.0

Дата: 16 ноября 2026 года.

## Выбор процедур

На 24 целевых запросах исходного аудита: версия 4.2.2 — **16/24**, версия 4.3.0 — **24/24**. Это регрессии и перефразировки для выявленных проблем, не оценка всех возможных запросов. [Исходные запросы](routing-audit.json), [результаты по каждому](routing-results.json).

## Проверка ответов на одинаковых заданиях

Два свежих контекста получили одинаковый пакет из десяти учебных задач и ограничения на инструменты. Один использовал Vovan OS, второй не читал её инструкции. Третий модельный проверяющий получил обезличенные варианты A/B с изменённым порядком и заранее заданные критерии.

| Вариант | Выполненные критерии, первый прогон |
|---|---|
| Без инструкций Vovan OS | 30/30 |
| С Vovan OS | 29/30 |

Один ответ Vovan OS оказался оборванным внутри строки таблицы: формально корректный JSON содержал неполный статический аудит. Ошибка сохранена в исходном ответе, а не скрыта исправленной копией. Усилена проверка завершённых пунктов и содержимого записанного файла; отдельный повтор этой задачи описан ниже.

Результат первого прогона **не показывает превосходства Vovan OS**. Возможная польза системы — повторяемый процесс и управление рабочими материалами — требует проверки на более разнообразных задачах и реальном использовании. Этот результат не подтверждает экономию токенов, рост продаж или популярность.

## Повтор неполного аудита

Свежий контекст записал [полный ответ на ту же задачу](response-audit-followup.json) после усиления правила проверки полноты. Затем сессия остановилась по лимиту. Основной исполнитель проверил сохранённый файл: четыре законченных пункта, четыре исправления, подтверждение по исходному HTML и явные границы статического анализа. Три критерия выполнены по этой проверке; это не повторная слепая оценка. Первоначальный результат 29/30 сохранён и не пересчитан.

## Исполнение

Штатные проверки пройдены на Linux и Windows: [GitHub Actions](https://github.com/Grezorg/vovan-marketing-skills/actions/runs/43847589535). Учебный HTML прошёл Chromium на ширинах 320, 390 и 1366: проверены отсутствие горизонтального переполнения, переход к форме, отказ для пустого ввода и неверной площади, результат правильной учебной заявки, отсутствие внешних запросов и ошибок консоли. [Браузерный отчёт](../examples/service-launch/checks.json).

Последующий [прогон](https://github.com/Grezorg/vovan-marketing-skills/actions/runs/43900087462) выявил периодическую ошибку Windows `Permission denied` при конкурентной записи памяти. Убрана запись начального байта до получения блокировки: Windows позволяет блокировать область пустого файла. Добавлена проверка ожидания уже занятой блокировки пустого файла; конкурентный тест выполняет 25 записей пятью группами. Проверки не отключены. Статус последней ревизии — в [актуальных запусках CI](https://github.com/Grezorg/vovan-marketing-skills/actions/workflows/validate.yml?query=branch%3Amain); ранний зелёный прогон не подменяет проверку исправления.

Приём настоящих заявок, другие браузеры и пилот с людьми не проверены. Локальная среда запрещала запуск Chromium; браузерный тест выполнен в CI.

## Ограничения

Один прогон, одна унаследованная модель сессии, учебные входы и модельная оценка. Точный идентификатор модели, настройки сэмплирования и расход токенов не измерялись. По десять задач выполнены в одном контексте каждого варианта. [План добровольного пользовательского пилота](pilot.md) подготовлен; участники не приглашены и результаты не выдуманы.
