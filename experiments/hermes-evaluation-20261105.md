# Проверка Hermes на короткой переписке

Дата проверки 5 ноября 2026 года.

Проверена связка официального Hermes Agent v0.22.7 и локальной Qwen 3.5 4B. Два вымышленных диалога воспроизводят ситуацию, когда исполнитель предлагает деталь, а заказчик либо ещё не ответил, либо явно одобрил её и отменил другой элемент.

## Полученный результат

| Пример | Наблюдение | Время |
| --- | --- | --- |
| 1. Нет следующего ответа заказчика | Агент правильно различил просьбу о регулируемых ножках и предложение исполнителя о шестигранной гайке. При этом явно не отметил отсутствие согласования именно этого варианта и добавил предположения об угле регулировки и креплении лампы. | 28,66 с |
| 2. Заказчик одобрил ножки и убрал лампу | Агент правильно передал требуемое состояние макета, но назвал исполнителя автором цитаты заказчика и выдумал последующее согласие исполнителя убрать лампу. | 15,51 с |

В такой конфигурации результат требует сверки с исходными репликами. Автоматически переносить его в окончательное клиентское ТЗ преждевременно. Успешный статус GitHub Actions подтверждает выполнение программы, а качество текста оценивается выше отдельно.

Два коротких примера не дают общей оценки всем моделям, совместимым с Hermes. Память между сессиями, инструменты, работа с файлами и расписание в этом прогоне не проверялись. Повторные запуски для статистики не выполнялись.

## Воспроизводимость

- Код Hermes закреплён на коммите b200f5bc60e31588ba2cb60e288029c4a54ba5fa.
- Локальный движок Ollama 0.40.14.
- Локальная модель qwen3.5:4b, идентификатор в ollama list d8b0f5e9760c, размер 3,3 ГБ.
- Контекст 65 536 токенов, max_tokens=1600, reasoning_config.enabled=false.
- Отдельный экземпляр AIAgent на каждый пример, enabled_toolsets=[], skip_memory=true, skip_background_review=true.
- Запуск на стандартном GitHub-hosted Ubuntu runner. Эти времена не являются замером ноутбука пользователя.
- Входные данные полностью вымышленные. Имена и оригинальная переписка клиента не опубликованы.

## Полные входы и ответы

### case-1

**Вход**

Вымышленный диалог. Заказчик пишет исполнителю. «Макет тумбы подходит. Дополнительно покажите снизу регулируемые ножки, чтобы выровнять тумбу на неровном полу. Сверху можно поставить настольную лампу». Затем исполнитель пишет помощнику. «Для примера сделай ножки с шестигранной гайкой и сам выбери лампу». После этого сообщений заказчика нет.

Составь краткое ТЗ для следующего макета. Укажи, что попросил заказчик, что предложил исполнитель и какие детали остаются открытыми. Для каждого вывода приведи короткую фразу из переписки и назови её автора. Отвечай по-русски.

**Ответ Hermes, без редактирования**

```text
**ТЗ для следующего макета тумбы:**

*   **Поведение заказчика:** Подтвердил текущий дизайн корпуса, но добавил требование о регулировке высоты ножками для неровных полов и указал место для настольной лампы сверху. (*«Дополнительно покажите снизу регулируемые ножки...»* — Заказчик).
*   **Предложение исполнителя:** Предложил решение с шестигранными гайками на ножках и выбор конкретной модели настольной лампы. (*«Для примера сделай ножки с шестигранной гайкой и сам выбери лампу»* — Исполнитель).
*   **Открытые детали:** Точный угол регулировки ножек, тип механизма фиксации высоты, конкретная модель лампы и ее крепление к поверхности стола.
```

### case-2

**Вход**

Вымышленный диалог. Исполнитель пишет заказчику. «Для примера предлагаю регулируемые ножки с шестигранной гайкой и настольную лампу». Заказчик отвечает. «Ножки с шестигранной гайкой оставьте именно такими. Лампу уберите, её в комплекте нет».

Составь краткое ТЗ для следующего макета. Укажи, что попросил заказчик, что предложил исполнитель и какие детали остаются открытыми. Для каждого вывода приведи короткую фразу из переписки и назови её автора. Отвечай по-русски.

**Ответ Hermes, без редактирования**

```text
Заказчик требует регулируемые ножки с шестигранной гайкой без настольной лампы; исполнитель сначала предложил комплект с лампой, а затем согласился убрать её. Автор: исполнитель («Ножки с шестигранной гайкой оставьте именно такими. Лампу уберите»). Открытыми остались цена и точный тип регулировки ножек.
```

## Замечания по запуску

В первом рабочем запуске Qwen 2.5 3B была отклонена Hermes до выполнения заданий из-за минимального требования контекста 64 000 токенов. Дальнейшая проверка выполнена с Qwen 3.5 4B и настроенным контекстом 65 536 токенов.

Ранний прогон с исходными настройками запущен отдельно. Его итог будет отражён после завершения.
