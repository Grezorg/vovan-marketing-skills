# Vovan Marketing OS RU — PRO v3.2 + 54 модуля

Готовый комплект для маркетинговых задач под российскую аудиторию. Версия 3.2.0, 20.09.2026.

## Как пользоваться с телефона

1. Распакуй ZIP в приложении «Файлы» или другом архиваторе.
2. Для новой задачи прикрепи **Vovan_Marketing_OS_RU_PHONE.txt**. В нём уже собраны надстройка, все 54 русские инструкции, полный PRO v3.2, примеры и российский контекст.
3. Напиши: «Используй Vovan Marketing OS RU. Создай [что нужно] для [продукт и город]. Начни с вопросов с вариантами ответа и возможностью написать свой».
4. Если хочешь без вопросов: «Режим AUTOPILOT. Недостающее выбери сам, существенные предположения обозначь».

Если приложение принимает и умеет распаковывать ZIP, можно прикрепить весь архив и попросить начать с SKILL.md. Если архив не читается, прикрепи извлечённый PHONE.txt. Простое скачивание или прикрепление не устанавливает скиллы навсегда; в новом чате файл может понадобиться снова. Интернет нужен для актуальных исследований и внешних действий, но все русские инструкции доступны в файле офлайн.

## Что внутри

- `SKILL.md` — управляющая PRO-надстройка и правила брифа.
- `skills/ru-*/SKILL.md` — 54 русских модуля: 50 маркетинговых и 4 модуля дизайна и проверки.
- `references/pro-v3.md` — все 42 раздела твоей PRO v2 с уточнениями и 6 новыми разделами.
- `references/ru-context.md` — российская аудитория, каналы, экономика и проверка фактов.
- `references/routing.md` — выбор модулей по задаче.
- `CATALOG_RU.md` — таблица соответствия всех 54 модулей оригиналам.
- `upstream/marketingskills/` — полный неизменённый оригинальный набор и справочники на английском.
- `source/Vovan_Marketing_OS_PRO_v2.md` — твой исходный файл без изменений.
- `examples/REQUESTS_RU.md` — готовые запросы.
- `SOURCES.md`, `NOTICE.md`, `LICENSE`, `SOURCE_MANIFEST.json` — источники, авторство, лицензия и зафиксированная версия.
- `Vovan_Marketing_OS_RU_PHONE.txt` — единый переносимый русскоязычный файл.

Это 50 маркетинговых адаптаций + Frontend Design (модуль 51) + аудит, тестирование и доработка (52–54) + отдельная управляющая надстройка. Адаптация меняет рабочие решения под рынок и сохраняет связь с оригинальными методами. Она не является построчным переводом всех сотен англоязычных вспомогательных файлов.

## Как устроена работа

Система читает контекст → задаёт только нужные вопросы → выбирает профильные модули → создаёт результат → проверяет факты и работу. Вопросы идут порциями по 1–3; есть готовые ответы, собственный вариант и «выбери сам». По простой задаче не запускаются все 54 модуля.

Основные изменения: рубли и география, сегментация по ситуации покупки, российские каналы по задаче, Метрика и связь с продажами, экономика маркетплейсов, доступные способы оплаты, проверка реальных условий и поддержка малого/нулевого бюджета. Никаких вымышленных отзывов, тарифов, гарантий роста и «нейрокнопок покупки».

## Репозиторий и использование комплекта

Репозиторий комплекта: `Grezorg/vovan-marketing-skills`. Сохраняй структуру: относительные ссылки работают внутри всего комплекта. Передавай агенту корневой SKILL.md и доступ ко всей папке; он будет читать нужные модули.
В среде, поддерживающей папку личных скиллов, устанавливай весь комплект как один управляющий скилл с вложенными материалами по правилам этой среды. Копировать один ru-модуль без общих references и оригинала недостаточно для сохранения всех ссылок. PHONE.txt — самостоятельный вариант для обычного чата.
Создание этого архива не создаёт новый GitHub-репозиторий, не подключает рекламные кабинеты и не запускает публикации. Актуальные условия площадок проверяются при конкретной работе; отмеченные непроверенные сведения перечислены в SOURCES.md.

«Используй приложенный Vovan Marketing OS RU. Нужен лендинг для [продукт] в [город]. Главная цель — [действие]. Бюджет на продвижение — [сумма] ₽. Задавай вопросы с готовыми вариантами, рекомендацией и моим ответом. После брифа подготовь результат целиком».
