# Vovan OS

Русский рабочий помощник для самозанятых и маркетологов: сайты, контент и материалы для клиентов с сохранением проекта. Версия **4.3.0**.

## Получите первый результат

| Задача | Что написать | Что получите |
|---|---|---|
| Проверить сайт | «Проверь сайт: [ссылка]. Покажи подтверждённые проблемы и готовые правки» | Замечания с доказательствами, приоритеты и исправления |
| Подготовить лендинг | «Собери лендинг для [услуга, город]. Контакт: [способ связи]» | Страницу и проверку согласованного пользовательского пути |
| Подготовить контент | «Сделай пост и сценарий Shorts о [тема]. Бюджет 0 ₽» | Связанный комплект; создание видео — при доступных инструментах |

## Как пользоваться

- Если Vovan OS уже установлена, просто дайте задачу. Названия файлов и команд знать не требуется.
- В обычном чате прикрепите [лёгкий стартовый файл](Vovan_OS_START_RU.txt). Это ограниченный текстовый режим; прикрепление не устанавливает навык навсегда.
- Для полного комплекта поручите среде с управлением навыками установить этот репозиторий. Начальная инструкция — [SKILL.md](SKILL.md). Способ установки зависит от приложения.
- Для локальных помощников нужен Python 3.12. Диагностика: `python scripts/doctor.py`. Проверка: `python scripts/run_checks.py`. Отдельные файлы можно читать без Python.

## Продолжить проект

Скажите «Создай паспорт проекта», «Покажи мои проекты» или «Подготовь передачу проекта в другой чат». Актуальные файлы и исправления сохраняются в частном хранилище проекта. Общий код системы не предназначен для личных данных.

## Что внутри

75 предметных процедур, 18 основных разделов, 6 русских справочников. Полный [каталог](CATALOG_RU.md) открывайте по необходимости. Дополнения охватывают исследования, дизайн, видео, документы и программы; выбор зависит от конечного результата.

## Стоимость и границы

Исходники доступны по лицензиям комплекта. Модель, генерация видео, хостинг и внешние сервисы имеют собственные условия. Система проверяет доступность перед работой; бесплатную квоту и отсутствие списаний нельзя обещать без данных. Фоновое обучение и автономный сервер в комплект не входят.

Штатные проверки, отдельные сценарные прогоны и результаты сравнения описываются раздельно. Нет подтверждённого обещания роста продаж, просмотров или экономии токенов.
