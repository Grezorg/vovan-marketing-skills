# Vovan OS v4 — единая русская система
Рабочий комплект Вована для ChatGPT: маркетинг, исследования, карточки товаров, медиа, сайты, документы, таблицы, боты и проекты.
Начать со SKILL.md. Выбирать материалы через CATALOG_RU.md или references/catalog.json. В установленной среде достаточно поручения «Используй нашу систему и сделай…».
Для обычного чата прикреплять Vovan_Marketing_OS_RU_PHONE.txt; при ограничении контекста читать нужные материалы выборочно. Прикрепление файла не устанавливает навык навсегда.
Рабочие инструкции русские. Код, идентификаторы и лицензии сохранены. Старые копии и англоязычные рабочие руководства убраны из активного дерева и доступны в истории GitHub.
Проверка комплекта: python3 scripts/validate.py. Личные состояния хранить отдельно от публичного репозитория.
