# Улучшить Vovan OS

Начните с воспроизводимой задачи в Issues. Покажите исходные обезличенные данные, текущий результат и нужное изменение. Для нового сценария объясните, почему не подходит существующий.

Правьте существующий раздел, сохраняйте русские инструкции, лицензии и ссылки на первоисточники. Добавьте проверку реального найденного сбоя, обновите версию и сгенерированные файлы через scripts/build_release.py. Затем выполните scripts/run_checks.py. Личные состояния, ключи и клиентские материалы не включайте.

Изменение считается готовым после проверки результата и совместимости; число новых файлов не служит показателем пользы. Сравнение качества ведите по evals/README.md. Присылайте обычный pull request с объяснением задачи, изменения и выполненной проверки.
