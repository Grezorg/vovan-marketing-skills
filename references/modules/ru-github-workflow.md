# Изменения GitHub без потери работы

Прочитать соответствующий модуль references/core/software.md от корня системы, текущие материалы проекта и ограничения пользователя. Использовать только доступные инструменты и профильные навыки.

## Процедура

Установить точный репозиторий, ветку и исходный коммит. Прочитать AGENTS.md и текущие файлы. Не перезаписывать посторонние незакоммиченные изменения.
Сделать связанные правки одним логическим изменением. Удалять только прочитанные файлы в согласованном объёме, проверяя ссылки и замены. Обычная история Git сохраняет восстановление; не переписывать её без отдельной причины.
Проверить синтаксис, зависимости, ссылки и сценарий задачи. Просмотреть diff и исключить секреты, пользовательские данные и случайные файлы.
Обновлять ветку с проверкой ожидаемого исходного SHA. При конфликте перечитать изменения и согласовать их с текущей работой, не применять force вслепую.
После сохранения проверить новый коммит и содержание главных файлов. PR описывать по конечному поведению и реально проведённым проверкам.

## Результат и проверка

Выдать порученный результат и подтверждённые проверки. Обозначить нерешённые дефекты и недоступные проверки. При существенном исправлении сохранить правило в пределах проекта. Происхождение методик — [NOTICE.md](../../NOTICE.md).
