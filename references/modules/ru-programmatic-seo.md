# Полезные страницы из данных

Российская адаптация `programmatic-seo` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Набор данных, тип страниц, спрос, регионы, шаблон, объём и CMS.

## Порядок работы

1. Выбрать применимую механику из оригинала: каталог, локации, сравнения, интеграции, примеры, термины, подборки или калькуляторы.
2. Проверить, есть ли для каждой страницы собственные данные и отдельная задача пользователя. Одной подмены города или ключевого слова недостаточно.
3. Спроектировать поля, источники, обновление и проверку полноты. Для региона подтвердить реальную возможность доставки/обслуживания; не создавать фиктивные офисы.
4. Создать шаблон с полезным ответом, фактами, различиями, внутренними ссылками, контактным/покупательским сценарием и метаданными.
5. Сначала подготовить малую выборку разных случаев, включая неполные данные. Определить правила не публиковать/не индексировать бесполезные комбинации.
6. Проверить canonical, пагинацию/фильтры, sitemap, дубли, доступность и контроль качества после обновления данных; затем предложить масштабирование.

## Результат

Модель данных, шаблон, примеры страниц, матрица публикации/индексации и план обновления.

## Проверка качества

Каждый URL имеет самостоятельную пользу; нет массовых дорвеев, вымышленных адресов и несуществующего ассортимента.
