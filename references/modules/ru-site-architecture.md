# Архитектура русскоязычного сайта

Российская адаптация `site-architecture` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Тип бизнеса, предложения, сегменты, регионы, существующие URL и задачи пользователей.

## Порядок работы

1. Разделить задачи посетителей: выбрать услугу, сравнить, узнать цену, проверить доверие, заказать и получить поддержку.
2. Сгруппировать страницы по понятной логике продукта; город и направление добавлять только при реальной разнице предложения и контента.
3. Сопоставить кластер спроса с одной основной страницей. Выделить категории, карточки, услуги, сравнения и справочные материалы.
4. Продумать короткие подписи меню, хлебные крошки и контекстные переходы. Мобильная навигация должна вести к действию без глубокого поиска.
5. Для существующего сайта сохранить значимые адреса или составить таблицу редиректов; описать canonical и правила для фильтров.
6. Показать компактную карту сайта, таблицу URL и связей; выбрать язык/транслитерацию URL последовательно, не менять рабочую структуру ради вкуса.

## Результат

Карта сайта, таблица «страница → аудитория → запрос → действие → ссылки», правила URL и миграции при необходимости.

## Проверка качества

Нет страниц-сирот, конкурирующих дублей и фиктивной региональности; важный путь работает на телефоне.
