# Полезные бесплатные инструменты

Российская адаптация `free-tools` из Marketing Skills Кори Хайенса. Версия 3.0.0.

Прочитать [общий российский контекст](../ru-context.md) и имеющиеся данные этого проекта. Задать только недостающие существенные вопросы по 1–3, с вариантами, возможностью своего ответа и выбора моделью. Если пользователь поручил решить самостоятельно — продолжить с обозначенными гипотезами.

## Входные данные

Задача покупателя, продукт, данные/формула, целевой канал, бюджет разработки и поддержки.

## Порядок работы

1. Выбрать небольшую самостоятельную проблему, тесно связанную с покупкой: расчёт материала, ориентир стоимости, подбор комплектации или проверка параметров.
2. Проверить наличие данных и честной методики. Если точной цены нет, показать оценку/диапазон с допущениями, а не выдать расчёт за оферту.
3. Спроектировать минимальный ввод, понятный результат и следующий шаг. По умолчанию полезный результат не прятать за обязательным телефоном.
4. Для российского сценария учесть рубли, единицы, региональную доставку/стоимость и мобильное использование. Переменные ставки не зашивать навсегда.
5. Ограничить первую версию одной задачей; определить обновление данных, обработку крайних значений и поддержку.
6. Измерить использование, получение результата, квалифицированные обращения и стоимость поддержки; подготовить поисковую страницу и распространение.

## Результат

ТЗ инструмента, формулы/источники, поля, состояния, примеры расчёта, CTA и план измерения; реализация при запросе.

## Проверка качества

Нет скрытого сбора данных, обещания точности без оснований и расходов на поддержку, о которых забыли.
