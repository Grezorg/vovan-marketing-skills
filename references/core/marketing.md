# Маркетинг и контент
Определить продукт, географию, аудиторию, ситуацию покупки, результат, главное действие, канал и бюджет. Прочитать references/ru-context.md, выбрать профильные модули через references/routing.md и references/catalog.json.
Для исследования применять ru-customer-research и ru-competitor-profiling; для оффера — ru-product-marketing и ru-offers; для цен — ru-pricing. Не заменять эти процедуры общей ролью маркетолога.
Для полного лендинга: контекст → оффер → структура и тексты → дизайн → реализация → главный путь → аналитика. Применять ru-copywriting, ru-cro, ru-frontend-design; техническую проверку выполнять через ru-web-design-audit, ru-webapp-testing и ru-design-polish по найденным проблемам.
Кампанию связать одной логикой, адаптировать к выбранным площадкам. Одиночный пост не расширять до ненужных писем. Выдавать готовые материалы, фактические расчёты или приоритетные исправления; гипотезы отмечать отдельно.
Текст для копирования выдавать через writing-blocks при доступном навыке. Публиковать и отправлять только в границах поручения.
