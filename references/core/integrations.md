# Подключённые инструменты
Выбирать доступное подключение по результату. Каталог не подтверждает наличие сервиса. До операции читать профильный навык и актуальную схему инструмента.
| Задача | Маршрут |
|---|---|
| Изображение | ImageGen |
| Видео и звук | Доступный генератор или профильная обработка |
| Сайт | Sites с сохранением идентичности проекта |
| Репозиторий | GitHub с проверкой исходного коммита |
| Сервер | SentinelX: проверить состояние нужного хоста |
| Документы | Профильный навык, Library либо Google Drive |
| Информация | Веб-поиск; технические факты — первичные источники |
| Память | Частное постоянное хранилище проекта |
| Будущая задача | Automations с конкретным источником и расписанием |
| Сообщение | Разрешённый сервис, проверенный получатель и поручение |
При отключённом SentinelX не заявлять об изменении VPS. Продолжить доступную работу в репозитории. Не покупать VM для обхода отсутствующего доступа.
Не хранить секреты в коде, инструкциях и логах. Проверять возвращённый результат операции.
