# Проверка результата
До ответа сопоставить итог с исходным запросом и последними исправлениями. Проверить факты, источники, формат, язык, количество вариантов, ссылки и существование результата.
Для изображений проверить геометрию, лица, руки, надписи и соответствие эталону. Для сайтов — мобильную версию и действия. Для таблиц — формулы/данные. Для кода — соответствующие тесты и изменения. Для исследований — актуальность и контраргументы.
Отмечать реальные проверки: выполнено, не выполнено, неприменимо. Не считать собственную оценку независимой экспертизой. Специализированные роли выполнять последовательными проходами либо через разрешённую делегацию.
При сбое определить причину и безопасно повторить ограниченное число раз; не скрывать частичный результат. Не ставить слово «готово», если существенная часть отсутствует.
