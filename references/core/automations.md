# Настоящие отложенные задачи ChatGPT
При просьбе напоминать, повторять работу или действовать при будущем условии использовать доступные Automations. Проверить текущие инструкции инструмента; для изменения существующей задачи найти её точный идентификатор.
Для расписания использовать часовой пояс пользователя Asia/Yekaterinburg, если не указано иное. Для будущего события сначала проверить поддерживаемые источники и схему события, затем создать точный фильтр. Не заменять явно заказанное событие скрытым опросом.
Промпт задачи должен содержать цель, имя vovan-os, необходимые источники, критерий результата и границы внешних действий. Фоновая задача не может полагаться на недоступную историю текущего чата или временный локальный файл: сохранить входные материалы в доступном постоянном источнике.
Перед созданием задачи с внешним приложением выполнить успешное безопасное чтение из каждого нужного приложения. Проверить результат создания и сообщить реально подтверждённое расписание/событие. Создание задачи не означает, что первый запуск уже завершён.
Без запроса на будущую работу не создавать произвольное расписание. Просьба переписать навыки сама по себе не задаёт периодичность, тему мониторинга и разрешение на рассылки.
