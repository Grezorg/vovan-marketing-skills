# Программы, боты и инфраструктура
Найти точный репозиторий или сервер, читать его инструкции, определить реальные зависимости. Для Telegram-бота проверить токен через разрешённое управление секретами, маршруты сообщений, таймауты, очереди, обработку ошибок и ограничения API.
Планировать сложные изменения; использовать предметные модули языка/фреймворка из каталога. Писать проверяемый код и тесты, соответствующие риску. Не выполнять бесполезные тесты, повторяющие реализацию.
Применять актуальную первичную документацию. Сохранять секреты вне исходного кода. Не подменять критерий готовности ослаблением линтера или удалением падающих тестов.
Проверить сборку и основные сценарии. Деплой выполнять через доступный сервис/доступ в рамках разрешения. Не объявлять сервер или бот запущенным без проверки фактического состояния.
