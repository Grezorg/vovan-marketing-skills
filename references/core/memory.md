# Проверяемая память проекта
Хранить компактные записи: факты, решения, исправления, уроки, открытые задачи. Указывать проект, дату, источник и степень подтверждения. Не переносить правила одного проекта в другой без основания.
Перед продолжением прочитать актуальный документ проекта или память OS. Видимое состояние и текущая версия файла важнее старой записи. При конфликте сохранить новое подтверждённое решение и отметить прежнее как заменённое.
Использовать `scripts/state.py show`, `checkpoint` и `remember` с JSON через stdin. Локальная запись ещё не означает постоянное сохранение: для состояния в навыке прочитать навык создания навыков, проверить изменения и синхронизировать его репозиторий. Для документов проекта использовать его постоянное хранилище и профильный навык.
Сохранять только нужные для работы сведения, без токенов, паролей и полного содержимого личных сообщений. При словах «запомни» выполнить сохранение и сообщить его реальный результат. Не обещать встроенную глобальную память ChatGPT, если была записана только память OS.
