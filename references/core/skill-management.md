# Развитие собственной системы
Сохранять один установленный навык Vovan OS и его идентичность. Канонический публичный источник — https://github.com/Grezorg/vovan-marketing-skills. Перед правкой читать актуальный skill-creator и обе текущие копии.
Добавлять модуль только для самостоятельной повторяемой задачи. При совпадении входов, результата и проверки улучшать существующий. Количество модулей не считать показателем качества.
Инструкции писать по-русски; код, идентификаторы и лицензии сохранять точно. Для удаления фиксировать причину и сохранённую замену. Не копировать чужие перехватчики и несуществующие команды.
Выполнять scripts/validate.py, проверять маршруты и реалистичные сценарии. Для существенных изменений проводить независимые проверки в рамках разрешённой делегации.
Публичный источник обновлять обычным коммитом без переписывания истории. Установленный навык сохранять через его репозиторий по skill-creator. Не публиковать references/state/os-state.json и личные файлы проекта. В конце отдельно сообщить результат обеих синхронизаций.
