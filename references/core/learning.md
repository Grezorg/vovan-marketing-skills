# Обучение на подтверждённых исправлениях
После существенной ошибки или успешного повторяемого приёма записать: контекст, наблюдение, изменение поведения, проверку результата и область применения. Отличать факт от гипотезы; собственное предположение не превращать в правило пользователя.
Использовать `scripts/state.py learn`: одинаковое доказательство не повышает уверенность повторно. Переводить урок в действующее правило после двух разных подтверждений либо прямого исправления пользователя. Применять только в соответствующем проекте.
Периодически оценивать применимость активных уроков в ходе работы. Устаревшее правило помечать заменённым; не удалять историю молча. Для значимого повторяемого процесса улучшать собственный модуль через навык создания навыков и проверку.
Это обновление правил и процедур, не изменение весов модели. Не запускать обучение фонового сервиса или платный API автоматически. Если пользователь запросил регулярный обзор уроков, создать реальную задачу ChatGPT через automations с согласованным временем и доступными источниками.
