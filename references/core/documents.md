# Документы, таблицы и презентации
Выбрать профильный навык по результату: Word/Docs, PDF, таблица, презентация. Читать существующий файл, сохранять его идентичность при изменении и учитывать актуальную версию.
Создать содержимое, структуру и оформление, проверить расчёты, формулы, переносы и визуальный вид. Выполнить рендер и проверку, когда того требует профильный навык.
Сохранять пользовательский результат через доступное постоянное хранилище. При изменении заменять нужную версию, не создавать случайно новый документ. Дать рабочую ссылку на файл после успешного сохранения.
Если нужен просто короткий текст для копирования, выдать его непосредственно в сообщении/блоке текста. Не навязывать скачивание файла.
