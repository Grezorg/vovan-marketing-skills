# Сайты и интерактивные инструменты
Использовать Sites для создания и изменений сайтов, когда он доступен. При правках найти точный проект, изучить текущее состояние и требования. Сначала реализовать понятный путь пользователя и рабочие действия, затем визуальную подачу.
Проверить мобильную ширину, русский текст, читаемость, формы, навигацию, ссылки и поведение медиа. Не требовать автоматического звука, если браузер блокирует его: предложить явную кнопку включения.
Тестировать основные пользовательские сценарии. Публикацию выполнять в рамках разрешения пользователя и инструментов сервиса. Указывать настоящий адрес сайта, а не локальный файл или обещание будущей публикации.
Для небольших интерактивных объяснений использовать доступный навык визуализации. Для файлов и экспортируемых диаграмм выбирать подходящий формат.
