# Первый полезный результат

При «как начать», «быстрый старт» или первом знакомстве с системой предложить три результата: проверить сайт, подготовить лендинг услуги, сделать контент из одной темы. Если задача уже названа, сразу перейти к ней. Не проводить обзор всех 75 процедур.

1. Восстановить известные данные из текущего проекта. Запросить только недостающее, без которого нельзя получить полезный результат; обычно достаточно ссылки, описания услуги или темы.
2. Проверить нужные возможности по [короткому протоколу](capability-check.md). Для простого текста не устраивать диагностику всех подключений.
3. Выполнить выбранный [сценарий](workflows.md). В конце показать готовый результат, выполненную проверку и существенный нерешённый пункт.
4. Для продолжительной работы сохранить паспорт и контрольную точку. При «покажи мои проекты» следовать [памяти](core/memory.md).

## Где запускать

| Среда | Как начать | Чего не считать установленным |
|---|---|---|
| Здесь, при установленной Vovan OS | Обычное поручение, например «Проверь мой сайт: ссылка» | Упоминание сервиса не подключает аккаунт |
| Обычный чат с файлами | Прикрепить Vovan_OS_START_RU.txt и дать задачу | Файл не устанавливает навык навсегда; лёгкая версия не содержит весь каталог |
| Codex с поддержкой личных навыков | Поручить установить комплект из канонического репозитория через штатное управление навыками | Не выдумывать универсальную команду установки для всех клиентов |
| Локальные помощники | Python 3.12; python scripts/doctor.py и python scripts/state.py projects | Локальная диагностика не проверяет внешние аккаунты |

Окончательное название функции, доступность и способ установки определять по текущей среде. Не обещать одинаковые возможности разных тарифов и приложений.

## Примеры начала

- «Проверь сайт [ссылка]. Нужны пять подтверждённых проблем и готовые правки».
- «Собери лендинг для [услуга, город]. Контакт [способ]. Не придумывай отзывы и цены».
- «Подготовь пост и сценарий Shorts о [тема]. Бюджет 0 ₽; сначала проверь необходимые инструменты».
- «Покажи мои проекты и предложи, что продолжить».

Если подключение отсутствует, выполнить доступную часть и точно назвать формат результата. Подключение и покупку не выдавать за выполненные.
