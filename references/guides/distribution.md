# Продвижение, поиск и запуск

## Канал
Выбирать канал по ситуации спроса и доступности аудитории. Для сформированного спроса оценивать поиск, для локальной записи — карты и профили, для демонстрации — соответствующие сообщества и авторов. Статус подключения и расходы проверять до действия.
Начинать с узкого проверяемого сегмента. До платной рекламы обеспечить работающий путь заявки, критерий лида и измерение. Бюджет 0 ₽ означает отсутствие денежных расходов, а не отсутствие работы.

## Реклама
Разделять гипотезы аудитории, обещания и формата. Согласовать объявление с посадочной страницей. Проверять полную стоимость клиента и маржу, а не только клики. Не переносить зарубежные кабинеты на российскую аудиторию по умолчанию.
Проверять реальные правила площадки при размещении; инструкции прошлой версии не подтверждают актуальные условия.

## Поиск
Сначала устранить препятствия индексированию, ошибки URL, дубли, неправильные канонические адреса и отсутствие полезного содержания. Каждой странице назначить намерение пользователя. Заголовок и описание писать для людей; разметку добавлять только для видимого подтверждённого содержания.
Архитектура сайта связывает категории, страницы услуги, вопросы и путь заявки. Не создавать массовые одинаковые страницы ради количества.
Для видимости в ответах ИИ использовать понятные факты, источники, структуру и актуальность. Не гарантировать попадание в ответ или выдачу.

## Запуск и рекомендации
Перед запуском выбрать сегмент, обещание, канал, демонстрацию, путь заявки и критерий успеха. Ограничить первый тест посильной группой. Реферальный процесс должен иметь понятные условия, подтверждение результата и защиту от повторных начислений; не придумывать выплаты.
Карточку приложения проверять по реальному назначению, скриншотам, описанию, ограничениям и данным выбранного магазина.

## Результат
Выдать план с материалами, бюджетом, зависимостями, проверками и метриками. Публикацию и рекламный расход подтверждать по выполненной операции, а не по наличию плана.
