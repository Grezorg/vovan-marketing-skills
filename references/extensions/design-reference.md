# Подбор палитры и типографики

Читать из [создания интерфейса](../modules/ru-frontend-design.md), когда отсутствует утверждённый бренд или нужен осмысленный выбор нового направления. Для локальной правки сохранять текущую дизайн-систему.

Использовать [русскую подборку](design-library.json): 10 палитр и 5 шрифтовых сочетаний из данных UI UX Pro Max. Это стартовые варианты, а не обязательный стиль отрасли и не вся база исходного проекта.

## Выбрать по содержанию

1. Определить основную задачу, нишу и характер материалов. Найти 1–2 подходящих варианта по русскому полю «задача», сравнить с реальными фотографиями и оффером.
2. Собрать роли цветов: фон, текст, основной акцент, текст на акценте, карточка, граница. Поля «на основном» и «на акценте» относятся к конкретному фону; не менять их на белый автоматически.
3. Проверить контраст реальных сочетаний и состояний, включая ошибки, отключённые кнопки и фокус. Базовый ориентир: 4,5:1 для обычного текста, 3:1 для крупного текста; соответствие всего интерфейса требует отдельных проверок. Таблица цветов сама не подтверждает доступность сайта.
4. Выбрать не более двух шрифтовых семейств; в простом интерфейсе достаточно одного. Проверить фактически загруженный файл на русский текст «Съешь ещё этих мягких булок — 1 250 ₽», начертания, fallback и лицензию. Наличие названия в базе не подтверждает кириллицу конкретного файла.
5. Не переносить популярную латинскую пару автоматически. Если файл не содержит кириллицы, выбрать подходящий проверенный шрифт, а не оставлять незаметную смесь fallback и оригинала. До проверки локальных файлов использовать рабочий системный fallback.
6. Применить выбранные роли через существующие токены проекта. Проверить реальные длинные заголовки, мобильную ширину, клавиатуру и уменьшение движения средствами модулей 51–54.

Не утверждать, что необычная палитра повышает конверсию без данных. Не заменять выбранный пользователем стиль «лучшим» по рейтингу. Сначала выполнить содержательное решение и проверить на странице.

Локальная подборка доступна без сети. Загрузка шрифтов и внешних картинок требует доступных файлов или подключения. Источники, лицензия MIT и точная выборка: [происхождение](sources.json).
