# Арена 3

Запускать по явной просьбе, например «Арена 3: придумай начало для Shorts». Вести сравнение в одном проходе текущей задачи, без отдельных субагентов, фоновых запусков и внешних зависимостей. Прямые правки выполнять обычным способом.

1. Зафиксировать результат, обязательные ограничения и текущий вариант, если он есть. Выбрать до трёх критериев до подготовки вариантов. Для Shorts подойдут ясность первых двух секунд, достоверность обещания и причина досмотреть.
2. Подготовить ровно три подхода, различающиеся по сути. Дать по короткому примеру, достаточному для сравнения. При наличии исходного варианта оценивать его как четвёртый, базовый вариант.
3. По одним и тем же критериям назвать конкретный плюс и слабое место каждого. Отсеять варианты с нарушением обязательных требований. Непроверенные факты и прогнозы пометить. При равной пригодности выбрать более простой вариант. Если исходник лучше, сохранить его.
4. Один раз доработать выбранный вариант и выдать готовый результат с коротким объяснением выбора. Если ни один вариант не проходит обязательные требования, назвать препятствие. Не запускать новый раунд автоматически.

Для оценки использовать уже доступные материалы и только необходимые проверки. Не заявлять измеренную экономию лимита без данных. Метод вдохновлён [Arena](https://github.com/Jakeschincariol/arena-skill). Этот режим использует собственные инструкции Vovan OS.
