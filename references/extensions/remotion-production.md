# Воспроизводимые ролики Remotion

Применять из [модуля Remotion](../modules/ru-remotion.md) для анимаций, титров, инфографики и серий рекламных роликов. Для генерации новых видеосцен по промпту выбирать профильный генератор; Remotion собирает композицию из кода и материалов.

## Подготовить проект

Прочитать package.json, точку входа и существующие композиции. Зафиксировать версии Node, React, remotion и пакетов @remotion; сохранять совместимые версии и lockfile. Существующий проект не переинициализировать. Для новой зависимости использовать принятую команду проекта; не запускать чужой установщик навыков.

Уточнить результат по поручению: интерактивный просмотр или готовый файл. При запросе ролика для скачивания выполнить экспорт. Для просмотра использовать доступную среду предпросмотра; отсутствие предпросмотра честно отделить от проверки экспортированного файла.

## Построить композицию

1. Указать width, height, fps, durationInFrames и входные параметры. Переводить секунды в кадры через фактический fps; не зашивать 30 во все расчёты.
2. Вычислять движение через useCurrentFrame() и interpolate()/spring() согласно установленной версии. CSS-анимацию по времени браузера не считать воспроизводимой покадровой анимацией. Вызывать useCurrentFrame в минимальном компоненте, которому нужен кадр.
3. Разделить сцены через Sequence и проверять локальное начало отсчёта кадра внутри каждой последовательности. На стыках проверить длительность перехода, суммарную длину и отсутствие случайного пустого кадра.
4. Заранее загрузить шрифты и материалы поддерживаемым API. Для локальных ресурсов использовать public и staticFile(). Выбирать компонент изображений, аудио и видео по текущей версии, проверив его импорты по официальной документации.
5. Для русского текста проверить ё/й, ₽, переносы, максимальную длину заголовка и безопасные отступы. Сохранить согласованные факты, лицо и геометрию товара. Шаблон параметризовать только для действительно повторяющихся вариантов.
6. Синхронизировать голос, музыку и титры по общей шкале. Если звуковая дорожка не создана, обозначить ролик как беззвучный. Не обещать бесплатную озвучку или внешний рендер без проверки доступа и условий.

## Экспортировать и проверить

Команду адаптировать к реальной точке входа и идентификатору композиции. При установленных зависимостях пример экспорта:

```bash
npx remotion render index.tsx VovanPromo out/promo.mp4 --codec=h264
ffprobe -v error -count_frames -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate,nb_read_frames:format=duration -of json out/promo.mp4
```

Использовать штатный браузер Remotion. Если текущая среда запрещает запуск браузера/сервера, не обходить ограничение: выбрать уже доступную разрешённую среду исполнения, либо выдать честный статус блокировки. Наличие пакета и успешная сборка не доказывают наличие MP4.

Проверить файл: кодек, разрешение, fps, длительность, число прочитанных кадров; осмотреть начало, конец и обе стороны каждого перехода. При наличии звука прослушать синхронизацию и обрезку. Чёрный кадр в конце считать допустимым только при намеренном затемнении.

Сохранить готовый файл и исходники в подходящих местах проекта. В результате указать длительность, формат, звук, выполненные проверки и ограничения. Успешный тест простого ролика не доказывает качество всех будущих сцен.

Источники, точные версии и объём переноса: [происхождение дополнений](sources.json). Это собственная русская рабочая процедура по документированным API; исходный управляющий навык Remotion целиком не перенесён.
